# Retro: CRM Y Mensajeria NORIX

## Resultado

Se aterrizo una lectura comparativa de cuatro referencias y se definio que NORIX construira su propio modulo CRM/mensajeria.

## Aprendizajes

- El inbox debe ser un producto completo, no solo una lista de mensajes.
- La idempotencia de webhooks es obligatoria.
- La autorizacion contextual es mas importante que copiar funcionalidades rapido.
- Las automatizaciones necesitan logs desde el dia uno.
- Las API keys deben tener scopes y revocacion si se expone API publica.
