# Decisions: Tablas Y Colecciones NORIX

## Decisiones

### 2026-07-28 - Tabla Canonica

Decision:

NORIX tendra un patron canonico de tablas/colecciones antes de crecer CRUDs.

Motivo:

El sistema administrara muchas entidades y necesita consistencia visual y funcional.

Alternativas:

- Diseñar cada CRUD por separado.
- Usar una tabla generica sin opinion de producto.

Consecuencia:

Primero se madura restaurantes/marcas como referencia, luego se replica.

### 2026-07-28 - Drawer Para Crear Y Editar

Decision:

Crear y editar desde colecciones usara drawer lateral.

Motivo:

Permite editar sin perder contexto de lista y se alinea con la experiencia tipo portal.

Consecuencia:

Los formularios deben ser compactos, claros y con acciones fijas.
